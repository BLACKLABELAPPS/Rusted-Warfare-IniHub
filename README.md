## 🌌 IniHub Repository for Rusted Warfare Modding & Mapping
IniHub is a high-performance, secure, and self-hosted backend infrastructure tailored specifically for Rusted Warfare (RW) developers, modders, and mappers. Built on top of Cloudflare Workers, R2 Storage, and Durable Objects, IniHub acts as a private or collaborative cloud storage hub. It allows you to seamlessly upload, store, organize, and sync every type of asset used in Rusted Warfare development.
Developed as a personal and collaborative backend for RW Studio, IniHub guarantees absolute data ownership. You deploy it within your own Cloudflare account. RW Studio never receives your credentials, API keys, or master secrets.
------------------------------
## 🛠️ Supported Rusted Warfare File Types
IniHub automatically categorizes, indexes, and manages all key file formats used in the Rusted Warfare modding and mapping ecosystem:

* .ini / .txt: Core unit configurations, logic scripts, custom behaviors, and game settings.
* .tmx / .tsx: Map files and tilesets created via Tiled Map Editor.
* .png: Textures, unit sprites, UI elements, projectile effects, and tileset graphics.
* .wav / .ogg: Custom sound effects, ambient tracks, and voice lines.
* .json / .jsonc: Configuration files, localization strings, and internal metadata.
* .template / .temp: Reusable configuration snippets and structural code blueprints.
* .effect: Dedicated visual fx files and particle emitter configurations.

## 🚀 Quick Deployment (No Terminal Required)

   1. Fork or Publish this folder as a public GitHub or GitLab repository.
   2. Launch the Deployer: Open the docs/index.html assistant via GitHub Pages, or use this direct button link:
   https://cloudflare.com
   3. Set Secret: During deployment, paste the unique token generated by RW Studio into the RW_BOOTSTRAP_SECRET variable.
   4. Connect: Once finished, copy your newly generated https://...workers.dev URL.
   5. Link to RW Studio: Paste the URL inside RW Studio and click Link Deployed Worker.

Cloudflare will automatically read wrangler.jsonc to provision your R2 Bucket and spin up the two required Durable Objects.

## 🧱 Architecture & Storage Layer

* Cloudflare R2: Securely hosts large assets including projects, raw files, working drafts, and historical backups prior to renaming.
* Durable Objects: Manages real-time stateful data such as active workspace participants, invitations, user presence, file locks, active sessions, and live history.
* Worker Secret: Uses high-grade cryptography to secure, sign, and authenticate access codes, active sessions, and collaboration invites.

------------------------------
## 🔒 Security & Data Integrity

* Zero-Knowledge Credentials: Never hardcode or commit the actual value of RW_BOOTSTRAP_SECRET.
* Git Protection: Local configuration files (.dev.vars and .env) are explicitly ignored by Git.
* Cryptographic Access: Connection tokens embed the Worker URL alongside an AES-GCM encrypted invitation payload.
* Path Sanitization: The API normalizes all incoming paths, explicitly blocking directory traversal (..), absolute path exploits, and the reserved .rwstudio directory.
* Concurrency Control: File writes utilize temporary locking mechanisms and ETag verification to prevent accidental overwrites during multi-user collaboration.
* Storage Limits: By default, the free tier limits managed RW Studio storage to 8 GiB to protect your Cloudflare account from unexpected usage.
